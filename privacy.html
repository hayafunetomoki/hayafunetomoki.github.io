プライバシーポリシー

チダトモ日記 / Chidatomo Diary　制定日：2026年10月26日

1. このツールについて

「chidatomo」は、「チダトモ日記」の運営者が、自分の動画を自分の YouTube チャンネルと Instagram アカウントに投稿するためだけに使う、自分専用のツールです。ほかの人には提供しません。

2. 使う情報と、その使い道

Google（YouTube とドライブ）

  • youtube.upload：運営者の YouTube チャンネルに動画を上げるためだけに使います。
  • drive.file：このツールが運営者の Google ドライブに作ったフォルダとファイル（確認待ちの動画、説明文、日報）を作る、読む、移すためだけに使います。ドライブのほかのファイルは見ません。

Meta（Instagram と Facebook）

  • 運営者の Instagram プロアカウントと、それにつながる Facebook ページを特定し、リールを投稿するためだけに使います。

動画を見た人や、コメントした人の情報は集めません。

3. 保存のしかた

ログインで受け取る鍵（アクセストークン）と、投稿の記録は、運営者の Mac の中だけに保存します。ほかのサーバーには送りません。

4. ほかの人への提供

受け取った情報を、売ったり、広告に使ったり、ほかの人に渡したりはしません。

chidatomo が Google API から受け取った情報の使い方と受け渡しは、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

5. YouTube API サービス

chidatomo は YouTube API サービスを使っています。YouTube の利用には YouTube 利用規約 が適用されます。Google による情報の扱いは Google プライバシー ポリシー をご覧ください。

6. アクセスの取り消し

  • Google：Google アカウントのサードパーティ アクセスの設定 から、chidatomo へのアクセスを取り消せます。
  • Meta：Facebook の「設定とプライバシー」→「設定」→「アプリとウェブサイト」から取り消せます。

7. データの削除

chidatomo が保存したデータは、運営者の Mac の中にあるものだけです。アクセスを取り消したうえで、Mac の中の鍵と記録を消すと、すべて削除されます。削除の依頼や質問は、下の連絡先にメールでお送りください。確認のうえ、30日以内に削除して、結果をお知らせします。

8. このサイトについて

このサイトは、Cookie やアクセス解析を使っていません。

9. 変更

このポリシーを変えるときは、このページを書き換え、制定日の横に更新日を書きます。

Privacy Policy (English)

Effective: October 26, 2026

1. About this tool. "chidatomo" is a private tool used only by the operator of Chidatomo Diary to post the operator's own videos to the operator's own YouTube channel and Instagram account. It is not offered to anyone else.

2. Data we access and how we use it.

  • Google youtube.upload: used only to upload videos to the operator's YouTube channel.
  • Google drive.file: used only to create, read and move the folders and files that this tool creates in the operator's Google Drive (videos awaiting review, descriptions and daily reports). No other Drive files are accessed.
  • Meta (Instagram / Facebook): used only to identify the operator's Instagram professional account and its linked Facebook Page, and to publish Reels.

We do not collect any information about viewers or commenters.

3. Storage. Access tokens and posting records are stored only on the operator's Mac. They are not sent to any other server.

4. Sharing. We do not sell, use for advertising, or share any data with third parties. chidatomo's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. YouTube API Services. chidatomo uses YouTube API Services. Use of YouTube is subject to the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

6. Revoking access. Google access can be revoked at Google Account third-party access settings. Meta access can be revoked in Facebook under Settings & privacy → Settings → Apps and websites.

7. Data deletion. All data stored by chidatomo is on the operator's Mac. Revoking access and deleting the tokens and records on that Mac removes all of it. For deletion requests or questions, email the contact below; we will delete the data and reply within 30 days.

8. This website. This website uses no cookies or analytics.

9. Changes. Any changes will be posted on this page with an updated date.

10. Contact. hayafune11@gmail.com
